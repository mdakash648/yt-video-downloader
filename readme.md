# 🎬 YT Video Downloader

A powerful and simple desktop application to download YouTube videos, audio, and playlists with ease.

---

## 🚀 Features

This application allows you to:

- 🎥 Download any YouTube video in high quality
- 🎚️ Change video quality before downloading
- 🎧 Extract and download audio directly from YouTube videos (MP3 format)
- 📂 Download full playlists easily
- ✅ Select specific videos from a playlist (custom download option)
- 📍 Set custom download location
- 🖼️ Download video thumbnail along with video
- 📊 View download progress, speed, ETA, and file size
- 📝 View detailed logs for every download task
- ⚡ Fast and optimized downloading experience

---

## 💡 Key Highlights

- Simple and user-friendly interface
- Supports both video and audio-only downloads
- Playlist management with selective download option
- Real-time download status tracking
- Lightweight and easy to use

---

## 📌 How It Works

Using the application is simple and straightforward:

1. 🎬 Paste the **YouTube video or playlist URL** in the input field at the top.

2. 📁 Choose your **download location** where files will be saved.

3. ⚙️ Select your preferred options:
   - Download entire playlist or specific videos
   - Enable **Audio only (MP3)** if you want only sound
   - Embed thumbnail as cover art (optional)
   - Choose **video quality** (Best available or custom)
   - Add browser cookies if required (for restricted videos)

4. 📋 If it's a playlist:
   - Click **Load / Refresh Titles**
   - Select specific videos or use **Select All / Deselect All**

5. ⬇️ Click the **Download** button to start downloading

6. 📊 Monitor real-time progress:
   - Download speed ⚡
   - ETA ⏳
   - File size 📦
   - Current status

7. 📝 View logs at the bottom to track everything in detail

8. ⛔ Use **Stop** anytime to cancel downloads

---

## 📌 Notes

- Make sure `ffmpeg.exe` and `ffprobe.exe` are placed in the same folder as the application.
- Internet connection is required for downloading content.
- Some videos may have restrictions based on YouTube policies.
